## 📦 Instalación

1️⃣ Clonar el repositorio:

```bash
git clone https://github.com/ManuCiber/Dashboard-React.git
cd Dashboard-React
```

2️⃣ Instalar dependencias:

```bash
npm install
```

3️⃣ Ejecutar en desarrollo:

```bash
npm run dev
```

La aplicación estará disponible en:

```
http://localhost:5173/
```
